# Valomize Randomizer

Valomize Randomizer is a premium Valorant agent randomizer built for teams who want to spice up their custom games. It offers a sleek, Valorant-themed interface with advanced features like role-based randomization, MVP/Bottom player constraints, and editable player names.

## Features

- **Agent Randomization**: Spin the wheel to get a random agent for each player.
- **Role Settings**: Control the composition of your team (e.g., 2 Duelists, 1 Sentinel).
- **Player Constraints**:
  - **MVP**: Can be assigned a specific role or left random.
  - **Bottom**: Forced to play Duelist (or other configured punishments).
- **Editable Players**: Add up to 5 players with custom names.
- **Premium UI**: Fully responsive, animated, and styled to match the Valorant aesthetic.

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion
- **Icons**: Lucide React

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/valomize-randomize.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd valomize-randomize
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

1.  Start the development server:
    ```bash
    npm run dev
    ```
2.  Open your browser and navigate to `http://localhost:5173`.
